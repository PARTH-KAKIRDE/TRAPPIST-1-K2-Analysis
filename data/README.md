# Data

This project uses publicly available observations of **TRAPPIST-1 (EPIC 246199087)** from **NASA's Kepler K2 Mission, Campaign 12**.

The raw data files are **not included in this repository** due to file size constraints and because they are freely available from the Mikulski Archive for Space Telescopes (MAST).

---

## Required Files

The analysis notebook requires the following datasets:

### 1. K2 Short-Cadence Light Curve

* Target: TRAPPIST-1 (EPIC 246199087)
* Mission: K2
* Campaign: 12
* Cadence: Short (60 s)

### 2. K2 Target Pixel File (TPF)

* Target: TRAPPIST-1 (EPIC 246199087)
* Mission: K2
* Campaign: 12
* Cadence: Short (60 s)

## Cached Outputs

Several stages of the pipeline are computationally expensive, particularly:

* PLD correction
* TLS transit searches
* CETRA transit searches
* Transit fitting

The notebook provides options to save intermediate products using:

```python
np.save(...)
```

and JSON exports.

For the first execution:

1. Run the full pipeline.
2. Save generated outputs to your data directory.

For subsequent executions:

1. Load the saved `.npy` and `.json` files.
2. Skip long-running preprocessing and search stages.

This significantly reduces execution time and improves the interactive analysis experience.
